# SectionHeading Atom

Standardized section headings driven by typography tokens.

## Variants
- `section-heading-primary`: Primary brown color.
- `section-heading-light`: White color for dark backgrounds.
- `section-heading-centered`: Centered alignment.

## Classes
| Class | Purpose |
| :--- | :--- |
| `.section-heading` | Base styles (font, size, line-height, margin) |
| `.section-heading-primary` | Primary color |
| `.section-heading-light` | Light color |
| `.section-heading-centered`| Text alignment center |

## Usage
```html
<h2 class="section-heading section-heading-primary">Our Services</h2>
```

## Tokens Used
- `--font-heading`
- `--font-size-xl`
- `--line-height-tight`
- `--color-primary`
- `--color-white`
- `--space-lg`
