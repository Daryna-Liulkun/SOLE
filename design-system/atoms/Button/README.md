# Button Atom

Foundational button component driven by design tokens.

## Variants
- `btn-primary`: Brown background, white text. Primary CTA.
- `btn-secondary`: Orange background, white text. Secondary CTA.
- `btn-outline`: Orange border, transparent background. Ghost variant.

## Classes
| Class | Purpose |
| :--- | :--- |
| `.btn` | Base styles (padding, font, radius) |
| `.btn-primary` | Primary color variant |
| `.btn-secondary`| Accent color variant |
| `.btn-outline` | Outline variant |

## Usage
```html
<button class="btn btn-primary">Text</button>
```

## Tokens Used
- `--color-primary`
- `--color-accent`
- `--color-white`
- `--space-sm`, `--space-lg`
- `--radius-md`
- `--font-size-md`
- `--shadow-orange`
